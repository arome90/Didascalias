Esta memoria recoge las actividades desarrolladas durante las prácticas curriculares realizadas en ActLab dentro del proyecto \textit{Didascalia VC - ACTLAB}, una aplicación de realidad virtual orientada al entrenamiento y la simulación de contextos educativos.

El trabajo se organizó en varios frentes técnicos complementarios: mejora del rendimiento en VR, evolución del sistema de estados para comportamientos del alumnado, refuerzo de la capa de conexión web y del manejo de mensajes, ampliación del sistema de conflictos y validación de despliegue en Meta Quest 3.

Además, se incorporaron mejoras operativas para el equipo, como la selección de servidores de prueba y la integración de contenido necesaria para sostener la nueva funcionalidad.

La memoria presenta el contexto de partida, describe de forma detallada la actividad técnica realizada, expone los resultados de verificación y relaciona las tareas con competencias adquiridas durante el grado, incluyendo una reflexión final sobre limitaciones y líneas de continuidad.
